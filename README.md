# 🚀 CodeAlpha Python Internship Projects

## 📌 Overview
This repository contains three Python projects developed during the CodeAlpha Internship.  
Each project demonstrates Python fundamentals, data structures, file handling, and automation concepts.  

---

## 🎮 Task 1: Hangman Game
**Description:**  
A classic text-based Hangman game where the user guesses a hidden word.  

**Features:**
- Predefined word list  
- Limit of 6 incorrect guesses  
- Console-based input/output  

**Concepts Used:** `random`, `loops`, `conditions`, `strings`, `lists`  



# 🤖 Task 2: Chatbot

## 📌 Overview
This project is part of the CodeAlpha Python Internship.  
It is a simple rule-based chatbot that responds to user input with predefined answers.  

---

## 🎯 Features
- Greets the user and says goodbye  
- Handles basic Q&A (like name, age, hobbies, etc.)  
- Provides default responses for unknown queries  
- Console-based interaction  

---

## 🛠️ Concepts Used
- `dictionary` for storing responses  
- `functions` for modular code  
- `loops` for continuous conversation  
- `string matching` for user input handling



# 📈 Task 3: Stock Portfolio Tracker

## 📌 Overview
This project is part of the CodeAlpha Python Internship.  
It is a Python program that calculates the total investment value of a user-defined stock portfolio.  

---

## 🎯 Features
- User inputs stock name and quantity  
- Hardcoded dictionary with stock prices (e.g., `{"AAPL": 180, "TSLA": 250}`)  
- Calculates and displays total investment value  
- Optionally saves results to `.txt` or `.csv` file  

---

## 🛠️ Concepts Used
- `dictionary` for storing stock prices  
- `input/output` for user interaction  
- `basic arithmetic` for calculations  
- `file handling` for saving results
